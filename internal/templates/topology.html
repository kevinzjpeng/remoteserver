About This Application

This is a server access management system built with Go. It provides:

  • SSH credential storage with encryption
  • GitHub OAuth authentication
  • Admin panel for managing credentials
  • Auto-generated topology diagrams

API Endpoints

The application provides the following JSON API endpoints:

  • GET / - Dashboard
  • GET /api/topology - Topology data
  • GET /admin/environments - List environments
  • GET /admin/servers - List servers
  • GET /admin/credentials - List credentials
  • GET /admin/logs - List access logs
